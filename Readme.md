

# Parathaa Manuscript Analysis

## About

This repository contains all the code for creating the data generated in initial release manuscript assocaited with Parathaa. Not that both the ```run.py``` and ```assignment_bench_multi.py``` can be used to generate all of the processed data that figures are made from in this manuscript. Individual figures can be generated from their corresponding scripts in ```src``` (although PATHs may need other be changed to those relevant to your install of this repository).
